## 12. Duplicate Handling Across Queries

1. **Normalize** every job to schema (title, company, location, description, job_url, site, is_remote, salary, etc.)
2. **Dedupe key** = `lower(title) + "|" + lower(company) + "|" + lower(location)`
3. **Merge strategy:**
   - Keep first occurrence (highest-priority query wins)
   - Preserve all source sites in `sources: []` array
   - Preserve earliest `date_posted`
4. **Cross-query dedupe** runs after ALL queries complete, not per-query.
